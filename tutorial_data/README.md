# Tutorial data

The notebooks automatically download the [example-data bundle](https://github.com/dsong-lab/spDecon/releases/tag/tutorial-data-v0.1.0).
To extract it manually, unpack `spdecon-tutorial-data.tar.gz` at the repository root.
Each dataset folder contains prepared arrays and saved fits.

Original dataset links are listed in the [main README](../README.md#public-data-sources).
Encoder weights are obtained separately following the G2 tutorial.
